# SpendWise – Personal Expense Tracker

A beginner-friendly web application made with HTML, CSS and JavaScript.

## Features
- Add an expense with a name, amount, date and category
- View total expenses, current-month expenses and transaction count
- See a category-wise spending breakdown
- Filter transactions by category
- Delete an expense
- Export expenses as a CSV file
- Save data in the browser using localStorage

## How to run
1. Download or clone this project.
2. Open the project folder.
3. Double-click `index.html` to open it in a browser.

No installation or server is required.

## Files
- `index.html` – application structure
- `styles.css` – design and responsive layout
- `script.js` – application logic and browser storage

## Important
Expenses are saved in the browser on the device where the app is used. They are not synced to other devices or accounts. Clearing browser data may remove saved expenses.

## GitHub Pages
To publish the app:
1. Create a GitHub repository named `personal-expense-tracker`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md`.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish your site. The website link will appear in the Pages section.
